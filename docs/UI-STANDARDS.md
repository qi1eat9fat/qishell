# Qi Shell UI 规范（实现级）

> 本文件把 `DESIGN.md` 的设计意图落成代码规则。`DESIGN.md` 是设计源，本文件是开发与巡检的判据。
> 发生冲突时：`DESIGN.md` > 本文件 > 现有实现。

---

## 0. 适用范围与例外

- 适用于 `src/workspace/`、`src/settings/`、`src/dialogs/`、`src/sftp/`、`src/terminal/terminal_view.rs` 与 `src/components/`。
- 唯一允许的色值例外：`src/terminal/theme.rs` 的 ANSI 调色板。
- 任何新增的裸色值、字号、圆角、命中区都必须先进入 `src/theme.rs`，否则视为违规。

## 1. 设计令牌

### 1.1 颜色

| 令牌 | 值 | 用途 |
|---|---|---|
| `BASE_RGB` | `#232136` | 应用背景、终端工作区 |
| `SURFACE_RGB` | `#2a273f` | 玻璃面板的理论底色 |
| `TEXT` | `#e0def4` | 正文、标题 |
| `SUBTLE` | `#908caa` | 说明、元信息、占位符 |
| `MUTED_STRONG` | `#b8b4d0` | 设置项标签、次要强调 |
| `MUTED` | `#6e6a86` | 更弱的信息（谨慎使用） |
| `FOAM` | `#9ccfd8` | 唯一强调色：连接状态、主操作、选中、焦点 |
| `GOLD` | `#f6c177` | 需要注意但不是错误 |
| `LOVE` | `#eb6f92` | 错误、断开、删除 |
| `LINE` | `line()` | 分割线、面板边框、普通描边 |
| `LINE_SUBTLE` | `line_subtle()` | 同一栏内部的细分隔 |

规则：

- 文字只用 `TEXT` / `SUBTLE` / `MUTED_STRONG` / `FOAM` 四档；不要新增第五种灰。
  例外：叠在壁纸上的浮层与弹窗用 `OVERLAY_TEXT`（对应 `MUTED_STRONG` 的位置）
  与 `OVERLAY_SUBTLE`（对应 `SUBTLE` 的位置），因为它们的背景会随壁纸明暗
  起伏，常驻面板的灰在亮色壁纸上会糊掉。
- `FOAM` 单屏占比不超过约 10%。
- 悬停底色只用 `hover_subtle()` / `hover_tint()` / `hover_tint_strong()` 三档。
- 危险色只用于不可逆操作与错误；恢复类动作（重连、重试）使用 `FOAM`。

### 1.2 字体与字号

| 令牌 | 字号 | 字重 | 用途 |
|---|---|---|---|
| `TYPE_TITLE` | 16px | 700 | 弹窗标题 |
| `TYPE_SECTION` | 13px | 600 | 分区标题、主机名、顶栏主机名 |
| `TYPE_BODY` | 13px | 400 | 正文、说明、表单控件 |
| `TYPE_LABEL` | 12px | 600 | 字段标签、设置项标题 |
| `TYPE_META` | 12px | 400 | 按钮、菜单、标签页、元信息 |
| `TYPE_MICRO` | 11px | 400 | 表头（全应用下限） |

规则：

- 功能文字 ≥11px；可交互标签 ≥12px；终端 ≥13px。
- 只用 400 / 600 / 700 三种字重。
- 等宽字体只用于终端与终端预览；必须使用 `assets` 提供的字体族，不写 `Consolas` / `Cascadia Code` 裸字符串（字体子集与回退由资产层负责）。
- 中文、英文、数字与符号统一由 HarmonyOS Sans SC 接管，正文共用 13px。
- 地址、指纹、文件大小与时间等数据字段也使用界面字体，数字通过 `theme::tabular_numbers()` 开启 `tnum` 保持等宽。

### 1.3 间距

4px 基准：4 / 6 / 8 / 12 / 16 / 22px；代码里只保留了真正用到的 `SPACE_MD`（12）与 `SPACE_XL`（22），其余按值直接写。

- 相关项贴近：6–8px。
- 普通控件的「图标 + 文字」统一用 `ICON_TEXT_GAP`（8px）；文件列表等紧凑区域保留 5–6px 的专用密度。
- 分组之间：18–22px，优先用分割线而不是继续加间距。
- 设置内容列最大 `CONTENT_MAX_WIDTH`（760px）。

### 1.4 圆角

| 令牌 | 值 | 用途 |
|---|---|---|
| `RADIUS_XS` | 4px | 小控件内部、标签关闭底 |
| `RADIUS_SM` | 5px | 徽标、色块、分组容器 |
| `RADIUS_MD` | 6px | 按钮、输入框、图标按钮、菜单项 |
| `RADIUS_LG` | 8px | 主机卡片 |
| `RADIUS_XL` | 10px | 弹窗、右键菜单 |
| `RADIUS_FULL` | 999px | 开关、状态点 |

### 1.5 边框

- 一律 1px。焦点态允许 2px，但只在输入框外壳上使用。
- 常规边框：`line()`。
- 栏内细分隔：`line_subtle()`。
- 选中态用左侧 2px `FOAM` 竖条 + 8% `FOAM` 底，不加粗整圈。
- 活动标签用顶部 2px `FOAM` 条。

### 1.6 阴影

- 面板、卡片、列表项：**不投影**。
- 弹窗、菜单、Toast：使用 gpui-kit 浮层自带的阴影；不手写第二层阴影。
- 状态点：实心点 + 2px 半透明细环（`theme::ring`），不用零偏移彩色阴影。

### 1.7 图标

- 线条图标统一 1.7px 描边，圆角端点。
- 尺寸只用 12 / 14 / 16 / 18px；代码里保留了 `ICON_XS` / `ICON_SM` / `ICON_LG` 三个令牌，16px 按值直接写。
- 全应用只使用 gpui-kit 的 Lucide 图标目录，不再内嵌自定义 SVG 图标。
- 同一语义只用一个图标；不在同一处混用两套图标库。
- 图标按钮必须有可访问名称（`aria_label` 或 tooltip）。
- 图标颜色跟随文字层级：默认 `SUBTLE`，悬停 `MUTED_STRONG`，激活 `FOAM`，危险 `LOVE`。

### 1.8 交互状态

| 状态 | 规则 |
|---|---|
| 默认 | 无背景或透明；文字按层级 |
| 悬停 | 只加白 3.5% / 5% / 8% 背景；不移动、不缩放 |
| 焦点 | 2px `FOAM` 边框或 gpui-kit 可见焦点环；不得只靠颜色变化 |
| 按下 | 白 8% 或主色加深一档 |
| 选中 | 8% `FOAM` 底 + 20% `FOAM` 边框 / 左侧 2px 竖条 |
| 禁用 | 透明度 0.5，不响应点击，保留可读标签 |
| 加载 | 保留原尺寸，文案改为进行时（如「正在测试…」），禁用重复提交 |
| 错误 | `LOVE` 边框 + 字段下方 12px 行内说明 |
| 危险 | `LOVE` 实底 + `BASE_RGB` 文字；仅不可逆操作 |

过渡：130–180ms，只改变颜色与边框；不使用位移、弹性、缩放。

## 2. 基础组件

所有组件必须从 `src/components/` 取统一实现；页面不得直接拼装 gpui-kit 的原始尺寸。

### 2.1 Button

| 变体 | 用法 | 规格 |
|---|---|---|
| Primary | 保存、连接、确认 | `FOAM` 实底，`BASE_RGB` 文字，高 33（表单）/ 32（普通） |
| Secondary | 取消、选择文件、次要动作 | 透明底，1px `line()`，`MUTED_STRONG` 文字 |
| Danger | 删除、不可逆确认 | `LOVE` 实底，`BASE_RGB` 文字 |
| Ghost | 图标按钮、工具栏 | 透明底，悬停白 5%；命中区与悬停底均为 28×28 |
| Text | 「恢复默认」等低权重动作 | 无边框无底色，悬停文字提亮 |

- 圆角 `RADIUS_MD`，文字 `TYPE_META`（12px）。
- 所有按钮高度 ≥32px；视觉更小的按钮用透明外框把命中区撑到 32px。
- 图标按钮命中区与悬停底均为 28×28，图标统一 14px；窗口控制按钮同为 28×28，图标 14px。
- 按钮内只放一个动作；加载态替换文案，不新增 spinner 改变高度。

### 2.2 Input / Textarea

- 高度 34px（单行），多行按内容增长。
- 1px `line()` 边框，`RADIUS_MD`，底色 `BASE_RGB` 60%。
- 内边距 10px 水平；文字 `TYPE_BODY`（13px）。
- 占位符 `SUBTLE`。
- 聚焦：2px `FOAM` 边框；错误：1px `LOVE` + 行内说明。
- 高密度表格内的输入允许 12px 文字、8px 内边距，高度仍与标准输入一致（34px），
  聚焦同样是外壳上的 2px `FOAM`。
- 所有输入必须有标签或 `aria_label`。
- 纯数字字段（字号、行高、并发数）文字居中（`text_align(TextAlign::Center)`），
  数字在固定宽度里稳在中间，步进时不会左右跳。
- 边框只由 `components::field` 的外壳画。gpui-kit 的 `Input` / `Textarea` /
  `Select` 原生外观在聚焦时会同时画 1px `ring` 边框和 3px 外环，叠在外壳上
  就是双边框，所以三个控件都关掉 `appearance`，由外壳统一。
  `tests/ui_standards.rs` 禁止视图层直接 `Input::new` / `Textarea::new` /
  `Select::new`。

### 2.3 Select

- 与 Input 同高（34px）、同圆角（`RADIUS_MD`）、同边框、同文字（13px）；走
  `field::select_field`。
- 触发器宽度按固定档位（160 / 210 / 280），不随窗口拉伸。
- 菜单使用 Popover 规范；选中项用 8% `FOAM` 底。
- 必须提供 `accessibility_label`，不能用占位符代替标签。

### 2.4 Checkbox

- Checkbox：16×16，2px 圆角，选中 `FOAM` 实底 + `BASE_RGB` 勾；命中区 ≥32px。
- 必须暴露开/关状态，并支持 Space 切换。

### 2.5 Dialog

- 宽度：确认类 440px，表单类 560px；指纹等特殊内容可到 500px。
- 圆角 `RADIUS_XL`，表面 `modal_surface(modal_alpha)`，边框 `line()`。
- 标题 `TYPE_TITLE`（16px，600）；说明 `TYPE_BODY`（13px，`OVERLAY_SUBTLE`）；
  字段标签与常规文字用 `OVERLAY_TEXT`。
- 标题与内容之间用 1px `line()` 分隔。
- 底部按钮：取消在左（Secondary），主操作在右（Primary/Danger）。
- 打开时聚焦首要控件（表单第一个字段 / 确认弹窗的主按钮）；Esc 关闭；关闭后焦点回到触发控件。
- 高风险弹窗（主机密钥、删除）`overlay_closable(false)`。
- 弹窗内容最大高度为视口减 40px，超出时内容区滚动，底部按钮固定。

### 2.6 Popover / Menu

- 表面 `theme::overlay(overlay_alpha)`：更深的 `OVERLAY_RGB` 加浮层不透明度
  （默认 45%），壁纸透得过来，白字仍然压得住。圆角 `RADIUS_XL`，边框 `line()`。
- 菜单项高 26px，圆角 `RADIUS_MD`，文字 `TYPE_META` / `OVERLAY_TEXT`；主机菜单与 SFTP 文件菜单都只用文字，不显示图标。
- 菜单右侧不显示快捷键字母；危险项文字 `LOVE`，禁用项整体降透明度。
- 键盘：方向键移动、Home/End、Enter 执行、Esc 关闭；打开后焦点进入菜单。
- 菜单宽度按内容，最小 160px；不在菜单里放长说明。

### 2.7 Toast

- 位置：主窗口水平居中、靠近内容区顶部，位于顶栏与标签栏下方。
- 宽度上限 320px；圆角 `RADIUS_LG`；表面浮层 alpha；边框 `line()`。
- 文字 `TYPE_META`；当前 Toast 同时承载成功、提示与错误，统一使用中性文字色，不画成功勾。
- 同一时刻最多 1 条；新消息替换旧消息；停留 3–4 秒，不阻塞操作。

### 2.8 Tabs

- 高度 36px；激活标签顶部 2px `FOAM` 条，底色抬升。
- 文字 `TYPE_META`；所有标签固定 180px，超出横向滚动。
- 关闭按钮图标 14px，命中区与悬停底均为 28×28，贴着标签最右侧。
- 溢出横向滚动；不截断标签文字到不可识别。
- 标签栏不放「新建标签」按钮：新标签都从主机列表或右侧工具栏（SFTP、设置）产生，栏里只列已有标签。

### 2.9 List / Table

- 行高：主机行 46px；表格行 30–32px。
- 悬停 `hover_subtle()`；选中 8% `FOAM` + 左侧 2px 竖条。
- 表头 `TYPE_MICRO`（11px），`SUBTLE`；排序指示用图标 + `FOAM`。
- 列宽固定，不提供拖拽手柄。
- 主机列表：新加的主机排在最上；整行可拖动排序，松手落在哪一行就插到那一行的位置，顺序立即写库、重启后保持。拖动需超过阈值才启动，单击选中与双击连接不受影响；拖起的预览是一枚带主机名的浮动小块，落点行用 `FOAM` 描边。
- 长文本统一省略号 + tooltip；不换行撑高行。
- 名字里的国旗（`🇭🇰` 这类区域指示符）一律画成 Twemoji 图片，尺寸取所在行的文字字号、与文字垂直居中；字体本身画不出旗面，不能直接交给字体。主机列表、标签标题、顶栏连接信息用同一套 `emoji::with_flags`，宽度不够时由文字出省略号、旗面保持完整。输入框没有「只改显示文字」的接口，所以名称输入框在打开时把名字开头的连续国旗摘出来另画在光标左侧，保存时再接回名字前面。
- 空状态：图标 20px + 一句说明 + 一个主操作；不放大面积插画。

### 2.10 顶栏

- 顶栏高 36px，左侧品牌；中间状态徽标、主机名、`user@address:port` 共享基线并水平居中；右侧只有窗口按钮。设置入口在右侧栏顶部、SFTP 图标上方。
- 品牌位是 18px 应用图标 + 应用名（`APP_NAME`，即「Qi Shell」），字号 `TYPE_SECTION`、字重 `SEMIBOLD`，间距 `ICON_TEXT_GAP`。图标素材只有 `assets/qishell.ico`（exe 与任务栏用）与 `assets/qishell-icon.png`（界面内用），不要再给品牌位另画字母方块或渐变徽标。
- SFTP 标签的主机名后追加 `· SFTP`，状态词保持「已连接 / 已断开 / 连接中」。
- 状态不能只靠颜色：徽标带文字，状态点带 `aria_label`。

## 3. 页面骨架

### 3.1 主窗口

| 区域 | 尺寸 |
|---|---|
| 顶栏 | 36px 通栏；品牌 + 居中的连接信息 + 窗口按钮 |
| 主机侧栏 | 264px（收起 36px），右侧 1px `line()` |
| 侧栏头部 | 36px，与标签栏同层 |
| 标签栏 | 36px |
| 终端区 | 剩余空间 |
| 右侧工具栏 | 36px |

- 侧栏与终端之间只有 1px 分割线，没有外层留白。
- 顶栏通栏；主机侧栏位于顶栏下方，侧栏头部与标签栏共用第二层，放标题、新建与收起按钮。
- 侧栏收起为 36px 窄栏，只保留展开按钮，与右侧工具栏同宽。
- 主机侧栏的顺序由用户掌握：新建的主机自动置顶，之后可拖动任意调整，顺序随主机一起存库。
- 顶栏只把非交互区域设为拖动区，按钮各自处理点击。
- 主工作区在内容之上只有「顶栏 + 标签栏」两层。
- 右侧工具栏图标按钮 28×28 命中区与悬停底，与顶栏图标一致；顶部依次是设置与 SFTP。

### 3.2 设置页

- 双栏：分类栏默认 180px，与标签同宽（`TAB_WIDTH`，150–300 可拖），右侧分割线因此与标签栏的分隔线对齐；内容列最大 760px 居中。
- 内容区内边距：上 24 / 左右 32 / 下 36。
- 设置页没有页面标题，也没有页面说明：内容列第一行就是第一个分区的标题（`layout::leading_section`，不画上分隔线、不留上间距），分区之间才用分隔线。设置项自己已经写清楚在调什么，再顶一句页面概括只是噪声。
- 分区：上间距 22px，1px `line()` 分隔，标题 13px 600。
- 普通行：左右布局，标签 12px 600 `MUTED_STRONG`，说明 11px `SUBTLE`，控件右对齐；行上下 9px。
- 滑杆行：标签与说明在上，滑杆占满整行；避免窄内容列把中文说明挤成竖排。
- 说明一律是「这一项怎么用」的一句话，可省则省：实现原因（为什么 GPUI 做不到、为什么这么取色、文件会被复制到哪）不写进界面，写文档；说明传空串时整行只画标签，不会留下空行。
- 滑杆外观由 `components/slider.rs` 的 `AppSlider` 统一：轨道 3px、拇指 10px，行高 18px 给指针留命中区；不用 gpui-component 默认的 6px / 16px。
- 分类项：高 32px，圆角 `RADIUS_MD`，选中 8% `FOAM` + 20% `FOAM` 边框。
- 分类栏没有搜索框：只有四个分类（外观 / 终端 / 连接 / SFTP），直接列出比先搜索再点更快。
- 终端页顺序固定为「字体 → 配色 → 预览」：先调字体与配色，最后在同一条预览里看合起来的效果。终端配色不放在外观页——它和字体只在同一个终端里一起生效。
- 主题卡片只画主题名与 16 色条，不在卡片里画文字样例；文字效果统一由页尾的「预览」承担，且预览用当前字体与当前配色画真实的几行输出。

### 3.3 列表页 / SFTP

- 顶部工具栏高 36px，与内容之间 1px `line()`。
- SFTP 视图宽度 < 900px 时隐藏远程侧的「权限 / 所有者」列，保留名称、大小、修改时间。
- 双栏与列之间均为静态 1px `line()`，不支持拖拽。
- 工具栏图标按钮统一 28×28；文字按钮 `TYPE_META`。
- SFTP 面板标题栏合并为一行：图标 + 本地/远程 + 面包屑路径 + 复制路径 + 刷新，不再单独保留路径栏。
- 面包屑祖先段 `SUBTLE`、当前段 `TEXT`，段间用 chevron；祖先段可点击跳转，长路径保留 tooltip。右侧复制与刷新为 28×28 命中区与悬停底。
- SFTP 面板标题、列头与文件行共用 10px 左缩进。
- 传输队列固定在底部，折叠后高度 32px；展开后最大占内容区 40%。

## 4. 巡检判定

一条 UI 问题至少满足以下之一才登记：

1. 违反本文件或 `DESIGN.md` 的硬性规则。
2. 同一组件在不同页面的尺寸、颜色、文案、状态不一致。
3. 状态缺失导致用户不知道发生了什么或下一步做什么。
4. 在最小窗口 / 150% DPI / 长文本 / 壁纸下不可读或不可操作。

严重度：

- **P0**：任务无法完成或违反硬性底线（<11px、<32px、焦点丢失、内容掉出屏幕、对比度不可读）。
- **P1**：明显增加出错概率或破坏信任（危险色误用、无初始焦点、状态只靠颜色、关键状态缺失）。
- **P2**：需要绕路或明显不一致（同类控件尺寸不同、长文本无截断、反馈不及时）。
- **P3**：不影响完成任务的打磨项。
