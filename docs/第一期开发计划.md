## 1. 目标与范围

### 目标

用 gpui-kit 0.6.1（GPUI）在 `E:\vibe\ssh\drift` 新建独立应用，逐屏还原原型 `index.html` 的视觉与交互，使用假数据驱动。所有交互（选中、标签、设置滑杆、对话框、右键菜单、Toast）都要可操作，不接真实后端。

### 本阶段包含

- 主窗口壳：自定义标题栏、264px 主机侧栏、连接栏、标签栏、终端模拟区、26px 状态栏。
- 无标签空状态、主机列表空状态。
- 主机行：状态点、名称、`user@address`、选中/当前态、悬停 `…`、右键菜单（连接 / 编辑主机 / 复制地址 / 删除主机）。

- 终端模拟：行号、提示符、命令与结果配色、滚动。
- 设置标签：外观（玻璃/轻量浮层/模态弹窗与遮罩/壁纸与清晰度、预模糊）、终端（字体/字号/行高 → 配色 → 预览）、SFTP、应用（窗口记忆开关，2026-10-22 已删除，外部编辑器并入 SFTP）；关键字高亮页已于同日整体移除。
- 对话框：新建/编辑主机、主机密钥确认、密码询问、删除主机确认。
- Toast、表单错误、空状态。
- 原生窗口：最小化 / 最大化 / 关闭（不做原型里的底部窄条和「窗口已关闭」页）。
- UI 集成测试与截图。

### 本阶段不包含（功能阶段再做）

- 真实 SSH / SFTP / PTY / 编辑器 / 数据库 / 钥匙串。
- MVP 中新增的页面：主机树分组与拖拽、搜索、开始页最近连接、SFTP 双栏、传输队列、编辑器、右侧栏命令片段/文件、其余对话框与菜单。
- 开发者模式、快捷键编辑器、在线升级、统计、外部 CLI。
- 窄屏（≤900 / ≤620）布局：桌面应用按 1280px 以上设计。

### 3.2 状态归属

- `Workspace`（`Entity<Workspace>`）持有全部界面状态：主机、标签、选中项、设置、外观、Toast、右键菜单锚点。
- `Tab` 保存自己的主机 id、连接状态、日志快照；设置标签是 `TabKind::Settings` 的单例。
- 对话框由 gpui-kit `Root` 的对话框层承载，内部表单状态放在各自 `Entity` 里；保存后回调 `Workspace`。
- 设置页不需要每类一个 Entity：外观使用 `Workspace.appearance`，其余设置放在 `SettingsState`，通过回调修改并 `cx.notify()`。
- 所有命令走 `actions.rs` 的 Action，按钮/菜单/快捷键都派发同一处理器。

### 3.3 主题与设计令牌

在 `theme.rs` 定义并写入 gpui-kit 全局 `Theme`：

| --- | --- |
| background | `#232136` |
| surface / sidebar / popover | `#2a273f`（带 alpha） |
| foreground | `#e0def4` |
| muted / muted_foreground | `#908caa` / `#b8b4d0` |
| primary（Foam） | `#9ccfd8` |
| warning（Gold） | `#f6c177` |
| danger（Love） | `#eb6f92` |
| info（Iris） | `#c4a7e7` |
| border | `rgba(86,82,110,.55)` |
| radius | 6px（小圆角 6–10） |
| 字体 | HarmonyOS Sans SC（中文、英文、数字与符号统一） |
| 等宽 | JetBrains Mono → Cascadia Code → Consolas |

- 字体：启动时 `cx.text_system().add_fonts(...)` 注册子集字体；主题字体统一用 HarmonyOS Sans SC，中英文、数字与符号共用同一字族，`TextStyle.font_fallbacks` 只用于字库子集之外的生僻字。
- 应用代码只读 `cx.theme()` 语义色；原型里的半透明面板色在 `theme.rs` 以辅助函数提供（`glass(alpha)`、`panel_alpha()`），不在视图里写死。

### 3.4 毛玻璃实现

- 窗口背景使用不透明 `WindowBackgroundAppearance::Opaque`，壁纸在应用内绘制。
- 壁纸层：`img(ImageSource::from_path(...)).object_fit(Cover)` 铺满窗口；清晰度控制暗色遮罩 alpha。
- 壁纸预模糊：图片解码后缩放到最长边 1200px，在后台线程做高斯模糊（三遍盒式滑动窗口近似，耗时与半径无关），生成 `RenderImage` 缓存；壁纸路径或模糊值变化时重建，旧图先 `drop_image`。所有面板共享这一张预模糊壁纸。不用 `image::imageops::blur`：它按半径逐像素卷积，debug 构建下 30px 半径要几十秒，滑杆拖动时永远算不完。
- 两级缓存：解码 + 缩放的结果（`wallpaper_source`）只与图片文件有关，换图才重做；拖动模糊滑杆只对这份像素重新模糊（1200px 约 40ms），去抖也从 120ms 降到 60ms，滑杆跟手。dev profile 另开 `opt-level = 1`，否则这一步的解码与缩放会慢一个数量级。
- 磁盘缓存：`data/wallpaper-cache/` 存缩放后的底图与当前模糊半径的成品（裸 RGBA + 8 字节宽高头，3MB 左右）。启动时同步读成品并直接作为第一帧；备份里只留这一张壁纸的这一对文件，换图或换模糊值时清理旧文件。没有缓存才在后台「解码 + 缩放 + 模糊」，期间铺纯色底而不画原图——先清晰再变糊的跳变比空背景更刺眼。
- 外观分四类（终端配色 2026-10-22 挪到设置 › 终端），滑杆值就是最终 alpha，派生比例收进 `src/settings/appearance_tokens.rs`：
  - 玻璃 `glass`：顶栏 ×0.92、标签栏 +0.06、聚焦标签 +0.16、活动标签 +0.30 是内部常量
  - 轻量浮层 `overlay`：菜单、下拉、Tooltip、Toast、终端查找栏与 SFTP 拖拽幽灵
  - 模态弹窗 `modal` + 遮罩 `backdrop`
  - 背景：壁纸、清晰度、壁纸模糊
- GPUI 不支持逐面板背景模糊，因此不再提供浮层/弹窗/遮罩的模糊滑杆；这三处靠不透明度下限保证可读性；这层原因只写在文档里，设置页不再有这行小字。壁纸是所有界面的底色：终端默认背景、浮层与弹窗都用半透明色叠在壁纸上，没有哪一层用纯色底。

### 与原计划的差异

| 项 | 实际做法 | 原因 |
| --- | --- | --- |
| 标题栏 | 自绘标题栏，未使用 gpui-kit `TitleBar` | 它把整条标题栏标成 Windows 拖动区，按钮会被命中测试当成标题栏而点不动 |
| 字体 | HarmonyOS Sans SC 子集（Regular / Medium / Bold） | 中英文、数字与符号统一字形；早期 IBM Plex Sans 方案保留在字体脚本里但界面不再使用 |

| 快捷键动作 | 关闭/确认按钮直接调用 `close_dialog` / `commit` | `Confirm`/`Cancel` 动作在对话框焦点路径下未触发，直接调用更可靠 |
| 自动化截图 | `scripts/screenshot.ps1`、`scripts/click.ps1` | DPI 与前台焦点会让普通截图/点击脚本失效，脚本已按系统 DPI 换算 |

### 2026-10-22 修复顶栏中段拖不动窗口

### 2026-10-23 SFTP 设置：本机默认打开路径
